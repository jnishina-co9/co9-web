Solution

ウェブページ・PDFでのマニュアル作成を自動化する

AIエージェント型ツール「Google Antigravity」向けに、業務マニュアル作成を自動化するSkill(AIへの動作指示書)を開発しました。テキスト原稿とスクリーンショットを渡すだけで、AIが構成からデザインまで自動生成し、Web版・PDF版どちらにも対応したマニュアルに仕上げます。

Specification

技術スタック
Google Antigravity Markdown HTML / CSS / JavaScript
動作環境 「.agents/skills/manual-creator/」フォルダに2つの指示ファイル(動作指示ファイル、UI・デザイン設計書)を設置したAntigravityプロジェクト。生成物はプロジェクト配下の各フォルダに保存され、ブラウザで閲覧・印刷可能
制約・スコープ外 Google Antigravity環境が前提のため他の開発環境では動作しない/生成後の細かいレイアウト調整は手動対応が必要な場合がある
Concept

スクリーンショット撮影とコーディングを、AIに任せる

スクリーンショット撮影とHTMLコーディングという定型作業に時間を取られ、本来注力すべき構成や設計に十分な時間を割けないという課題がありました。動作指示書とデザインルールをそれぞれskillsファイル化することで、AIに一貫した品質のマニュアル作成を任せられる仕組みを構築しました。

01

チャットで指示するだけ

「マニュアルを作って」と伝え、タイトル・手順・画像を共有するだけで、AIが原稿作成からHTML生成までを自動実行。

02

スクリーンショットの自動取得

画像が手元になくても、対象のURLを伝えればAIが画面を開いて撮影しながら作成することも可能です。

03

動作指示書とデザイン設計書を分離

「動作の指示(処理フロー)」と「デザインのルール(配色・レイアウト)」を、それぞれ別々のファイルに分けて管理し、内容とデザインが混ざらない仕組みに。

04

仕様変更にもすぐ対応

手順が変わったときもAIに再作成を依頼するだけ。最新版のマニュアルを、いつでも早く提供できます。

Features

主な機能

1原稿からHTMLまで一括自動生成

チャットで指示するだけで、画像取得・原稿(manual.md)作成・HTML生成までを一気に実行。Antigravityのスキルとして常駐するため、いつでも誰でも同じ品質のマニュアルを再現できます。

2Web閲覧・PDF印刷のハイブリッド対応

生成されたファイルはブラウザで快適に読めるだけでなく、印刷専用のデザイン設定も組み込み済み。ブラウザの「印刷」を押すだけで、A4用紙やPDFとして美しいレイアウトでそのまま出力・保存できます。

3スマホ・PC両対応のレスポンシブデザイン

スマートフォンやタブレット表示にも自動対応。フォントや配色・レイアウトのルールがあらかじめ統一されているため、現場での確認でもオフィスでも見やすいデザインに仕上がります。

4プロンプト等のワンクリックコピー

マニュアル内に記載された長文テキストやプロンプト文(AIへの指示文)を、ボタン1つで素早くコピー可能。マニュアルを読む人がスムーズに実務を行える便利機能を標準搭載しています。

Flow

処理の流れは5ステップ

  1. 01

    準備

    マニュアルのタイトル・手順のテキスト・使いたい画像を用意します(画像が手元にない場合は、対象サイトのURLを渡すだけでAIが自動撮影も可能)。

  2. 02

    チャットで指示

    Antigravityのチャット画面で「マニュアルを作って」と伝え、用意した情報を渡します。

  3. 03

    スキルの自動読み込み

    AIがマニュアル作成用スキルを自動認識し、定義された処理フローとデザイン設計書を適用します。

  4. 04

    原稿・HTMLの自動生成

    プロジェクト内に専用フォルダを作成し、Markdown原稿(manual.md)とWebマニュアル(index.html)を一気に生成します。

  5. 05

    完成・確認・共有

    スマホ・PCどちらでも見やすく、PDF印刷にも最適化されたマニュアルが完成。ブラウザですぐに確認・活用できます。

UI / UX

使いやすさの工夫

プロンプトのコピー機能

手順内の長いテキストをワンクリックでコピーでき、他の作業への流用もスムーズです。

重要度が一目でわかる配色

重要な操作は目立つ枠、補足情報は控えめな枠で区別し、迷わず読み進められます。

スクリーンショットの自動取得

画像の準備が難しい場合も、URLを伝えるだけでAIが画面を開いて撮影してくれます。

原稿とデザインを分離した構成

manual.md(文章)とindex.html(デザイン)を分けているため、文章だけを直したいときも迷いません。
